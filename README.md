# SNP Array Design in Brassica juncea

## Overview
This project presents a Python-based pipeline for designing SNP-specific primers in *Brassica juncea*. The pipeline identifies target SNPs, designs primers, and validates primer specificity using BLAST.

## Features
- SNP-specific primer design
- Primer3-based primer generation
- BLAST-based primer validation
- High-throughput analysis across all 18 chromosomes

## Tools
- Python
- Primer3
- Biopython
- BLAST
- Pandas

## Input
- Genome FASTA
- GFF Annotation
- SNP List

## Output
- SNP-specific primer pairs
- Validated primers
